# stickmo-media

Balíky GIF-ov pre aplikáciu Stickmo (od WIZARD).

- `pack8.js` – balík č. 8: 135 GIF-ov v štýle tenkých čiar (Zubár, Šoférujem, Narodeniny, Jubileum, Sviatky, Nálady, Bežný deň, Šport, Romantika, Pozdravy a odpovede, Práca a remeslá, Počasie, Cestovanie)
- `pack8_0.bin`, `pack8_1.bin` – vektorové snímky animácií (deflate-raw JSON), ktoré `pack8.js` načíta

Aplikácia načítava súbory cez jsDelivr: `https://cdn.jsdelivr.net/gh/wizardsksro-sys/stickmo-media@<commit>/pack8.js`
